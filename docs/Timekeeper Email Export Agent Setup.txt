WHAT CHANGED
- Immediate best-effort review Excel and detailed Word report, with uncertainties disclosed instead of routine pre-draft questions.
- Full non-spam communication accounting, including untimed messages.
- Quarter-hour review allocations with underlying minutes retained.
- Eight-hour ordinary-day planning target and clearly identified internal policy remainder, preserving work over eight hours.
- Existing billing preserved, including non-billable case work with its assignment/task.
- Separate detailed reconstruction, import and report references.

CURRENT APP LIMITS
Final activity exports require approved whole minutes, employee_confirmed=true and real stable source IDs. Their import does not accept an hours column, best_effort_estimate or blank evidence IDs. Timekeeper 0.6.0+ also accepts the supported Review format after local confirmation, with limited duplicate detection. Instructions alone cannot remove app requirements.

In Timekeeper's Email imports settings, choose 15-minute rounding for quarter-hour output. Enable "Apply my Timecards and weekday fill settings to email imports" if desired; these additions are off for email by default. Check target, Timecards amount and partial-day needs. The agent previews policy additions separately and never fabricates filler evidence.

This package updates agent guidance only. It does not update the application, installer, permissions or live agent configuration. Update and test the existing shared agent before team rollout.

QUICK CHECK AFTER UPDATING
Ask for a day with known activity. Confirm the agent delivers REVIEW.xlsx and Word before routine questions, labels uncertainties, accounts for non-spam messages and preserves work above eight hours. Approve the proposal once, then verify the separate import workbook uses minutes and real source IDs. Import it in Timekeeper for review; submission is a separate deliberate action.

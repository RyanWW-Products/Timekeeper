# Timekeeper 0.12.0

Edit activity descriptions in Timekeeper before submitting them to Quickbase.

- In email review or the dashboard, double-click the activity/description field, press **F2** while focused on it, or select a row and choose **Edit description**.
- The larger editor supports multiline text, a character count, **Cancel**, and **Save description**. **Use original** restores imported text or the original dashboard description when available. Empty text, unsupported control characters and descriptions over 4,000 characters cannot be saved.
- Saved text appears in the submission preview and is validated again before writing. Changes clear the final review confirmation. Receipts contain the exact submitted description.
- Description edits survive hours changes, billing refresh and regrouping, and dashboard date selection changes. Fresh reads and imports start a new review. Standalone manual entries save their updated descriptions for later imports.
- Original email workbooks and source evidence remain unchanged. Editing an email activity keeps a previously matched manual entry counted once. Activities linked to existing Quickbase records are read-only because those records are not being submitted again.

The Excel format and shared agent instructions are unchanged. The installer preserves settings, credentials and submission history.

# Timekeeper 0.4.0

- Added Dark mode and three additional themes: Slate, Forest and Sand. The original Ivory theme remains available and is the default.
- Added **Appearance** in the sidebar and Settings, with live previews, accent colors, 100–120% interface sizing, Comfortable/Compact spacing, and a reset option.
- Appearance saves per user, separately from account settings. Cancel restores the previous look; changing themes preserves the current read session and timecard review.
- Applied themes throughout the workspace, settings, updates, dialogs, tables, date pickers and calendars, including disabled and selected states.
- Replaced decorative catchphrases with direct labels and instructions.
- Improved smaller-window layouts when using larger interface sizes. Review columns retain readable widths, with Date and Hours fixed while the remaining columns scroll.

Install over your existing version to retain settings, credentials, exports and submission history. Open **Appearance** to select a theme and choose **Save appearance** to keep it.

Verified with the 123 offline rules, API/storage and updater cases, plus WPF control, preference persistence, contrast and rendered UI checks. No live timecards were created during verification.

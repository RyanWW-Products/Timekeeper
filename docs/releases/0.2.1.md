# Timekeeper 0.2.1

- Removed the Quickbase user ID field from Settings. Identity discovery still happens automatically during Test connections, and changed account credentials invalidate the prior identity.
- Replaced the Copilot agent-creation screen with Getting started for team members. Everyone uses the owner's shared agent through the Shared Copilot agent link setting.
- Preconfigured the owner's shared Timekeeper chat link. Existing installations using the generic Copilot URL switch to the shared agent; custom links are preserved.
- Added a Quickbase token-help link in Settings and step-by-step token instructions in Getting started.
- Kept agent creation/update instructions in the source repository for the owner; removed those guides from the team installer and cleaned up copies left by older installations.

Existing account settings, tokens and submission history are preserved. The installer remains unsigned.

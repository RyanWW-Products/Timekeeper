# Timekeeper 0.2.2

- Replaced the generic "invalid numeric record ID" error with the Quickbase table, source record ID/name, field number, received value and expected format.
- Added selectable error text, Copy error details and Open Quickbase record to Settings. If the record's ID is unavailable, the error identifies its position in the query results instead.
- Accept exact whole decimal IDs such as `44.0`. Fractional, negative, zero-required and overflowing IDs remain invalid; nothing is rounded into another record.
- Filter open personal assignments before parsing their relationships, so an incomplete assignment belonging to someone else does not block the user's connection test. Explicit assignment search still validates all returned matches.
- Bound and redact diagnostic values; unrelated record content and API tokens are not included.

The reported screenshot did not contain enough information to identify its particular source record. This release fixes the diagnostic and two possible parsing triggers; a live connection retest is needed to establish the original cause.

Existing settings, tokens and history are preserved. The installer remains unsigned.

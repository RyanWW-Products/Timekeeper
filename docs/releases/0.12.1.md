# Timekeeper 0.12.1

Fixes partial submissions caused by multiline activity descriptions and adds a way to continue interrupted submissions from their saved receipts.

- Windows and Quickbase can represent the same line break differently. Timekeeper now treats CRLF, LF and CR line endings as equivalent when checking existing records and reconciling uncertain writes. Text, blank lines, spaces, hours and other fields are still checked. Receipts retain the exact reviewed text.
- In **Submission history**, select a partial receipt and choose **Submit remaining rows**. Review the saved remaining timecards and confirm to continue. This works with eligible receipts saved by older versions, including email-only submissions.
- Continuation uses the saved descriptions, hours, billing choices and selected dates. It rechecks account identity, current permissions, mappings, source data and existing Quickbase records. Confirmed-created rows are skipped. The original receipt is updated as remaining rows are submitted.
- Unknown or pending outcomes must first be reconciled with **Check selected result**. Receipts with rejected rows, unconfirmed billing or recovered deletions require separate resolution. Genuine data changes still block continuation to avoid duplicate or outdated timecards.

For a partial result caused only by multiline formatting, update, select that receipt and use **Submit remaining rows**. No new Copilot proposal or Excel import is needed.

The installer preserves settings, credentials and submission history. Agent instructions and the Excel format are unchanged.

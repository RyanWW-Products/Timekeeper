# Timekeeper 0.8.0

Email review now displays decimal hours: **0.25 h = 15 minutes**. Double-click an hours box or press F2 to edit. Edited hours are used exactly, while unedited activities keep your grouped rounding preference. **Use imported** restores the source duration. The workbook itself stays unchanged.

- Adjust billing in the activity table without changing the assignment or task. Quickbase permissions control whether a dropdown appears; defaults show the resolved billing status with green/nonbillable red indicators.
- Set **Fill weekdays to** and an hours target for this import, with a separate **Add Timecards** option. Fill recalculates after table edits and counts existing Quickbase hours. Work above the target is retained. Weekends receive no automatic additions.
- Choose **Cancel**, **Review in Timekeeper dashboard**, or **Submit directly to Quickbase**. Direct submission opens a preview of exact grouped timecards, additions, totals and warnings and requires the final confirmation checkbox. Changes clear approval. Both submission routes use the same live checks and saved receipts.
- Dashboard review preserves activity edits and import policy, including billing changes that regroup work. Later edits to final dashboard rows leave other rows and filler unchanged.

The minimal Excel format is unchanged: it still exports approved whole minutes. Word approval in M365 still precedes Excel generation. The updated agent handoff text describes the new controls; the template does not need replacement.

The refreshed Windows installer installs 0.8.0 and preserves settings, tokens and history. Validation uses synthetic data and fake Quickbase responses; no live timecards were written.

# Timekeeper 0.6.0

- Billing is read-only when the account cannot modify it. Defaults display Billable or Nonbillable when Quickbase exposes the rule inputs; unavailable inputs are labeled honestly.
- Double-click Hours, or press F2, to edit a duration before submission. Edits require warning acknowledgement and retain original hours in receipts. Other rows stay unchanged; review the daily total.
- Import the supported email review Excel layout after confirming the activities and limited duplicate checks. The supplied review layout, simple hours/totals formulas, attention notes and coverage limitations are supported. Genuine-source-ID final exports remain supported.
- Email-only setup clearly allows a blank Toggl token and uses Quickbase only.
- Updated agent instructions and context files accompany this release. Replace the old email agent files together.

The Windows installer includes version 0.6.0 and its runtime, preserves existing settings/history, and is also copied to installer/Timekeeper-Setup.exe for local distribution. No live timecards were created during validation.

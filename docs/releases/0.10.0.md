# Timekeeper 0.10.0

Add work directly in Timekeeper, keep it with your imported day, and review everything together before writing to Quickbase.

- **Add timecard** is available on the dashboard and in email review. Enter a loaded date, exact decimal hours, description and verified project/assignment/task. Edit or delete pending entries in their separate table; deletion requires confirmation. Every change resets review approval.
- Start a manual-only day with Quickbase configured, without Toggl or a Copilot file. New entries use the configured internal project/task. Nonbillable is selected only when your account can apply an override; otherwise the actual Quickbase default applies. An unavailable default remains unknown. Manual-only reviews have automatic Timecards and weekday fill off.
- Manual drafts are stored locally per Quickbase profile. A new read or import asks whether to append them or delete them. Deletion needs a separate confirmation, and the choice takes effect only after a successful read or accepted import. Failed or cancelled operations preserve the saved draft. Cancelling email review discards changes made in that window.
- Appended entries keep their dates, hours, descriptions and billing. They count before the import's configured automatic additions, so they reduce remaining weekday fill. Entries on dates excluded from submission stay pending.
- Exact, unambiguous matches with imported work count once; exact existing Quickbase matches are excluded from the new write only when the required fields and billing agree. Similar or uncertain matches remain for review with warnings. The preview identifies how each manual entry is handled.
- Confirmed-created entries are retired from the pending draft. Failed, not-sent and unknown outcomes remain pending. Resolve unknown results in Submission history before trying again.

The Excel schema and shared agent instructions are unchanged. Manual entries stay local instead of being added to Copilot proposals. The installer preserves settings, tokens and history.

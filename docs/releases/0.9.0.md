# Timekeeper 0.9.0

Find cases and assignments more easily, search tasks, and apply time directly to a project without creating an assignment.

- Assignment search includes all employees and statuses, including Active, Case Intake, Proposal and Review. Searches now match words across assignment/project/client names, support record IDs and names containing apostrophes, and ask for a narrower query above 200 results.
- Choose **Direct to project** in the lookup window to find a case and apply time without an assignment. The selected project must be present in Quickbase reference data and is checked again before submission. The email review table keeps your hours, task and billing choices. For the Toggl/Copilot workflow, add the project to the export and drag the updated file into Copilot again for a new proposal.
- Task dropdowns include search by name or ID. Searching or dismissing the dropdown preserves the current task; selecting a result applies the change and resets review confirmation.
- Billing defaults can resolve from readable inputs even when another lookup fails. Partial lookups and temporary metadata failures can be retried. **Refresh billing** updates defaults and permissions without discarding reviewed hours or overrides, and requires review confirmation again. Hover over an unavailable default for its specific reason. Hidden required fields and unsupported formulas still remain unknown.

The Excel workbook schema is unchanged. Updated agent instructions explain direct project mappings and the new controls. The Windows installer includes 0.9.0 and preserves settings, tokens and history. Checks use synthetic data and fake service responses; no live Quickbase timecards were written.

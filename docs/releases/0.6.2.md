# Timekeeper 0.6.2

Email workbooks now accept normal Excel dates, General/text date serials, native ISO date cells and unambiguous date text. Both the 1900 and 1904 date systems are honored. Ambiguous dates identify the worksheet and cell instead of guessing a day.

Mixed numeric/text durations and Excel Boolean values are supported while whole-minute, total, confirmation and duplicate checks stay in place. Date conversion is limited to work-date and reporting-period fields; IDs and durations are preserved.

Saved workbooks can be imported while Excel has them open. Timekeeper reads one bounded snapshot for both its content hash and workbook parsing. Save edits before importing. Unreadable or exclusively locked files show recovery instructions.

Adds an example Review workbook for M365 with exact headers, metadata, billing examples, communication accounting and template guidance. All example data must be replaced. Updated agent context files explain the supported formats.

Validated the user's October 12 review workbook: seven activities and 480 minutes, unchanged. No Quickbase records were written during validation. The refreshed Windows installer includes version 0.6.2 and preserves settings, credentials and history.

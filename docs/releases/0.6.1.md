# Timekeeper 0.6.1

Fixes the "Value cannot be null. (Parameter 'ptr')" error after confirming an email review workbook when the optional Toggl token was saved empty. Existing blank credentials now load correctly, and clearing an optional token removes its saved credential.

Malformed saved credentials now show instructions to re-save tokens in Settings instead of a pointer error. Quickbase access is still required for assignment lookup and submission. Toggl remains optional for email imports.

The Windows installer includes version 0.6.1 and preserves settings, tokens and submission history.

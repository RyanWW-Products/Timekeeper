# Timekeeper 0.2.0

- Windows installer with a bundled runtime; no Python or terminal needed.
- Toggl reads, Copilot Agent Builder file exchange, local proposal verification, reviewed Quickbase submission and durable receipts.
- Automatic Quickbase user ID detection from each user's token.
- Assignment lookup by assignment, project or client; matching results are included in a refreshed Copilot file.
- Per-user Timecards allowance and weekday fill target, defaulting to 0.17 hours and 8 hours. Longer days retain all work plus the allowance.
- In-app update checks, checksum-verified downloads and an installer upgrade that keeps settings and history.

The installer is unsigned. Live Toggl/Quickbase and tenant-specific Copilot operation still require a controlled check with your accounts. Microsoft 365 chat opens in your browser; embedded chat is not included.

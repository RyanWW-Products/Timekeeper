# Timekeeper 0.11.0

Choose your work date first, then add manual timecards, read Toggl or import email.

- A shared work-date panel sits above the Toggl / Quickbase and Email / Quickbase panels. Expand **More than one day** when you need a date range.
- **Add timecard** is available beside the date. New entries use that date even when a previous read used another day. Quickbase supplies the project/task choices and existing time; no Toggl connection or email import is required.
- Each source panel has a labeled status light for the selected date. Manual-only lookups do not count as imported data. Changing dates clears the previous active review and export while keeping saved manual drafts.
- Reads and imports offer to append or delete manual entries for the selected dates. Drafts on other dates stay saved and cannot prevent preloading a new day. Deletion still requires confirmation.
- **Open email Copilot agent** opens the team's separate email agent. Email Excel still supports dropping a file or clicking to browse. The workbook must contain activities for the selected date; multi-day imports start with those dates selected and retain their original dates.

The Excel format and agent instructions are unchanged. The Windows installer preserves settings, credentials and submission history.

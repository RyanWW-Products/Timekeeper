# Timekeeper 0.3.0

- Refreshed the entire Windows interface with warm ivory surfaces, deep green navigation, muted teal actions and subtle brass accents. Serif headings and monospaced totals add a restrained retro touch.
- Improved the main workflow's spacing, file targets, table selection, date inputs, disabled controls and keyboard-focus indicators.
- Grouped settings into clearer sections and restyled update messages, error details, assignment search and proposal dialogs.
- Added an empty history view and consistent active navigation. History timestamps now use local time, matching the selected receipt.
- Fixed automatic Quickbase identity discovery. It now verifies the token's current user through the supported table-scoped REST API, replacing the account-level XML request that rejected user tokens with HTTP 400. No manual user ID is needed.
- Preserved the existing time policy, proposal verification and explicit Quickbase write workflow.

Install over your existing version to retain settings, credentials, exports and submission history.

If connection testing previously reported HTTP 400, reopen Settings and choose **Test connections** after updating. Confirm that the Quickbase token is assigned to Case Manager and that you saved its token page. The new lookup has been checked against the current API contract and mocked responses; it has not been tested with your live token.

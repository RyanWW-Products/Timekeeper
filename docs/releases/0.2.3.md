# Timekeeper 0.2.3

- Update errors now explain when GitHub access is missing, when a saved token may have expired, and when repository or organization permissions need attention.
- Access errors open the GitHub access settings automatically. Instructions clarify that Timekeeper cannot use your browser's GitHub login and that update access is separate from Quickbase and Toggl.
- GitHub request limits show a separate message, and the update dialog scrolls when expanded help exceeds the available screen height.

This release includes the Quickbase record diagnostics from 0.2.2. Installing over an earlier version preserves settings, credentials, exports and submission history.
